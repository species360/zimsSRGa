# Collection data

A simulated dataset including information about individual collections.

## Usage

``` r
data(collection)
```

## Format

A data.frame object with 1382 rows and 5 variables:

- AnimalAnonID:

  Anonimized ID of the Animal

- RecordingInstitution:

  Anonimized ID of the Institution

- CollectionType:

  Name of the collection

- ScopeType:

  "Local" = Only private use or "Global" = Zims user use

- ChangeDate:

  Date of arrival in this collection
