# Death Information data

A simulated dataset including information about individual death
information.

## Usage

``` r
data(weights)
```

## Format

A data.frame object with 266 rows and 3 variables:

- AnimalAnonID:

  Anonimized ID of the Animal

- RelevantDeathInformationTypeID:

  ID of the cause of death

- RelevantDeathInformationType:

  Cause of death

## Source

Subset of a toy database created by the Species360 Development team in
08-2024
