# Parent data

A simulated dataset including information about individual parents.

## Usage

``` r
data(toy_parent)
```

## Format

A data.frame object with 1503 rows and 7 variables:

- AnimalAnonID:

  Anonimized ID of the Animal

- ParentOriginType:

  "ZIMS" or "Non-Zims"

- ParentType:

  "Dam" or "Sire"

- ParentAnonID:

  Anonimized ID of the parent

- Probability:

  Percentage of parentage certainty

- OffspringCollectionScopeType:

  Offspring collection at birth "Local" = Only private use or "Global" =
  Zims user use

- ParentCollectionScopeType:

  Parent collection at offspring birth "Local" = Only private use or
  "Global" = Zims user use
